# 9Router (fork purujawa06-bot)

🍴 Fork dari [decolua/9router](https://github.com/decolua/9router) — AI routing gateway + dashboard: satu endpoint OpenAI-compatible (`/v1/*`) dengan fallback multi-provider, OAuth/API-key, dan quota tracking.

## Install

- Docker: `ghcr.io/purujawa06-bot/9router:latest`
- npm: `npm install -g @rikipurpur/9router`

Update mengikuti git tags fork — setiap tag `v*` baru, dashboard & CLI menampilkan notifikasi update otomatis.
